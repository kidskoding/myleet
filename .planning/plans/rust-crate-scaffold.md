## Architecture

Stack: Rust binary crate next to the Go module. No layers yet. `main.rs` dispatches on the
first argument, the same way `internal/cli/cli.go` switches on `cmd`. Version identity lives
in its own module, mirroring `internal/version`.

### Components

| Component | Type | Purpose |
|-----------|------|---------|
| `version` | module | Build identity from `option_env!`, `string()` with Go's exact fallback |
| `main` | binary entry | `run(args, stdout, stderr) -> u8` like Go's `cli.Main`; dispatch `version` / `-v` / `--version`; everything else exits 2 "not ported yet" |
| `rust` CI job | GitHub Actions job | fmt, clippy, test on every push, separate from `quality` |

### New files

| File | Location | Purpose |
|------|----------|---------|
| `Cargo.toml` | repo root | Package `myleet`, edition 2024, `rust-version = "1.85"`, bin `myleet-rs` |
| `Cargo.lock` | repo root | Generated by `cargo build`, committed |
| `rust-toolchain.toml` | repo root | `channel = "stable"`, components rustfmt + clippy |
| `version.rs` | `src/` | Version identity + unit tests |
| `main.rs` | `src/` | Argument dispatch |

## Testing plan

| Test | Kind | Spec link |
|------|------|-----------|
| `string()` with version, commit and date set → `myleet 0.1.0 (abc123, 2026-11-14)` | unit | must-have: version format |
| `string()` with `dev` + `none` → `myleet (dev)` | unit | edge case 1 |
| `myleet-rs version`, `-v`, `--version` → exit 0, stdout starts `myleet ` | unit (`run()`) | must-have |
| `myleet-rs validate` → exit 2, stderr has `not ported yet` | unit (`run()`) | edge case 2 |
| `myleet-rs` with no args → exit 2, stderr has `not ported yet` | unit (`run()`) | edge case 3 |
| `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings` | lint | must-have: CI |
| `go vet ./...` and `go test ./internal/tui/...` still pass | regression | edge case 5 |

No data layer, API or UI in this feature, so those test groups do not apply.

To make `string()` testable without build env vars, it takes the three values as
parameters (`identity(version, commit, date)`), and a thin `string()` passes the
`option_env!` values.
